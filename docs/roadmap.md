# Roadmap

优先级是维护顺序，不是日期承诺；未完成项不计入当前功能。

## 开源与 Alpha 发布

- [x] 统一为 0.1.0-alpha.1，建立 [版本与发布规范](versioning.md)。
- [x] 选定自有代码/文档 [MIT LICENSE](../LICENSE)。
- [ ] 审查第三方 notice 与图标来源/再分发许可。
- [ ] 为当前预发布 补齐真实系统授权、网络切换/锁屏及流量证据。
- [ ] 确定公众可安装的签名/分发与保留身份的升级路径。
- [ ] 固定 SDK 和 OpenHarmony Go 来源、镜像 digest 与缓存准备流程。
- [ ] 验证 release-mode 构建，发布 tag/commit/checksums/notices/SBOM。
- [ ] 部署可信 CI，启用分支保护与私密漏洞报告；验证远程结果。
- [ ] 完成隐私数据流核验和真机可访问性验收。

## 后续工程改进

- 在有行为回归保护的独立变更中，将 `pages/` 下共享控制器、平台适配和
  显示缓存提取到清晰的 `client/` 边界；同步 import/test harness，不以搬文件
  代替模块解耦。本轮保留现有生产代码路径。
- 明确 legacy probe/tsnet ABI 的保留和弃用策略，不直接删除仍被工具使用的导出。
- 为发布增加可验证的生成证据、来源与校验和，避免固定产物名造成版本混淆。

## 功能探索（不承诺）

MagicDNS、IPv6、出口节点/子网、可靠后台恢复等各自需要设计、平台支持与
真实设备验收。当前 IPv4 Tailnet-only 行为保持不变。
