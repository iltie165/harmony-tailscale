## 更新内容

- 使用用户最新上传的发光网络节点深色 PNG 原图；AppScope 与 entry 源资源
  与上传文件字节一致，SDK 编译资源为 512×512 PNG。
- 登录成功（包含已认证 Starting）清除浏览器提示；认证与管理员审批保持
  不同状态。观察超时保留正确的“检查结果”操作；检查不重新登录或请求 VPN。
- 首次 VPN 启动不再等待 SDK Promise 返回才读扩展转交状态；参数遗漏时使用
  经过时间、owner、意图 revision 与已消费检查的私有启动请求。
- 已确认新宿主的转交不被晚到的 SDK rejection 误取消。真实失败、OFF、取消、
  代次变化仍终止连接。已有健康扩展的暖态 ON/OFF 不调用 SDK 启停。
- 初始化监听失败回滚本次已获得的核心，拒绝启动不能关闭账号宿主；
  未确认的清理维持 cleanup_pending，不谎报停止。迟到监听会被注销。
- 独立被跟踪的 VPN 开关状态与不可变恢复快照，避免原地修改漏通知。
- 转交期间前台恢复延后，成功清除对应恢复错误，保留不相关诊断。
- 最新提交的筛选在单飞查询结束后立即补查，旧响应不应用。
- 后台同步不增删加载行、无变化的设备行保留身份；“最近同步”只更新对应
  时间文字，与内容变更时间分开记录，旧显示缓存兼容。
