# 0.1.0-alpha.1 — 首个开源 Alpha（发行说明草稿）

状态：**候选，尚未发行**。没有版本 tag、公开 GitHub Release 或上架声明。
具体证据与首发条件见 [首发范围](../first-release.md)。

## 包含功能

官方登录/管理员审批状态、账号恢复、在线设备/筛选/详情、Tailnet IPv4 VPN、
取消/重试与资源清理状态、同一身份暖态 ON/OFF；本机和设备 IPv4 一键复制。
新增离线帮助、社区关于页、源码/反馈入口、隐私说明、离线开源声明与
先预览再复制的脱敏反馈摘要。

## 支持范围

HarmonyOS ARM64、最低 API24/目标API26，官方 Tailscale Go1.86.2 核心。
仅 Tailnet IPv4；不接管普通 Internet 或系统 DNS。
未支持 MagicDNS、IPv6、出口节点/子网、保证后台常驻/开机自动连接。

## 安装与升级

versionCode3004002 高于旧内部包3004001，原 bundle identity 保持不变。
覆盖升级须使用有效且兼容的签名；先关闭 VPN，不要先卸载。
**当前产物未签名，不可当成已验证的公众安装包。** 签名范围和真机升级尚待确认。

## 许可与隐私

自有代码/文档 MIT；上游保留各自条款，已提供链接 Go 模块与运行时 supplied
notices。素材许可仍待确认。账号状态保存在应用私有目录；反馈摘要本机生成，
不自动上传，也不包含账号、IP、节点标识、登录链接或原始日志。
