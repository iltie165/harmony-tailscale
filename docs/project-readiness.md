## 结构决策

`AppScope/` 和 `entry/` 属于 HarmonyOS Stage 标准；Go `core/` 含固定 C ABI 与
同目录单元测试；跨语言测试集中 `tests/`。保持这些位置可保留构建、NAPI
加载和 host harness 的现有契约。真正的模块解耦列入 [路线图](roadmap.md)，
需在后续有完整目标编译验证的独立变更中完成。
